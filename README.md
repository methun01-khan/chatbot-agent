🚀 Overview

ELF (Enhanced Learning Friend) is a smart conversational AI system designed to overcome the limitations of traditional rule-based chatbots. It understands user intent, context, and sentiment to provide more natural, human-like interactions.

✨ Key Features
💬 Natural Language Understanding
😊 Sentiment Analysis (Emotion Detection)
🔍 Real-Time Web Search
📝 Text Summarization
🎯 Intent Recognition
🏷️ Entity & Keyword Extraction
⚡ Quick Actions (Weather, News, Calculations)
🧠 Context-Aware Responses
🛠️ Tech Stack
Backend: Python (Flask)
Frontend: HTML, CSS, JavaScript
NLP: NLTK, TextBlob, VADER
Database: MySQL
Environment: Windows / Linux
⚙️ Quick Setup
git clone https://github.com/your-username/elf-chatbot.git
cd elf-chatbot
pip install -r requirements.txt
python app.py
🌐 Run Locally

Open your browser:

http://localhost:5000
🧠 How It Works
User input is processed using NLP
Sentiment & intent are detected
Relevant data is fetched (web/search/db)
Response is generated and returned in real-time
